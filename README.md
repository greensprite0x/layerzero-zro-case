# LayerZero (ZRO): разбор проекта перед запуском сети Zero

Аналитическая записка и доказательная база к ней. Срез данных — **22.10.2026**.
Автор: Попов Роман Сергеевич.

30 ноября 2026 года LayerZero запускает собственную сеть Zero и биржевой движок ATLAS —
на этом ожидании построена текущая цена токена ZRO. Записка проверяет, выдерживают ли
заявления проекта сверку с первоисточниками, данными бирж и блокчейном.

**Полный текст: [LayerZero_ZRO_кейс.pdf](LayerZero_ZRO_кейс.pdf)** (8 страниц, первая
страница — саммари).

## Основные выводы

1. **Текущая экономика не обосновывает оценку.** Выкуп токена идёт на $4–5,5 млн в год
   при капитализации $726 млн — отношение 150:1 против отраслевой медианы 30:1.
2. **Реальное предложение шире календарей разлоков.** 175,6 млн ZRO (44% обращающегося
   объёма) у самого проекта и 68,2 млн в эскроу-кошельках не имеют технических
   ограничений — только управленческие.
3. **Доступный рынок у́же заявленного.** Режим SEC для токенизированных акций рассчитан
   на пулы ликвидности, а ATLAS — книга заявок.
4. **Рынок втрое тоньше, чем показывают агрегаторы.** После исключения двух площадок с
   аномальными данными реальная глубина — $8,4 млн вместо заявленных $28,3 млн.

Отдельно разобрано, где на этом материале ошиблась бы языковая модель: семь примеров в
формате «вероятный ответ → факт → источник ошибки» (стр. 1 записки).

## Что в репозитории

### `data/` — собранные данные на дату среза

| Файл | Содержание |
|---|---|
| `сводка_держателей.csv` | 20 крупнейших держателей ZRO: баланс, тип адреса, владельцы мультиподписей, первое поступление, движения после сентября 2025 |
| `контрагенты.csv` | 11 адресов, через которые шли крупные переводы: тип, баланс, число контрагентов, основные получатели |
| `19-21_октября_крупные_переводы.csv` | все переводы ZRO от 1 млн токенов в окне разлока 20.10.2026 |
| `разлоки_цена.csv` | цена ZRO за 14 дней до и после каждого из 17 ежемесячных разлоков, с поправкой на движение биткоина |
| `площадки_спот.csv` | 132 торговые пары: объём и глубина рынка по каждой |
| `фьючерсы.csv` | 57 контрактов: открытый интерес и ставки финансирования |
| `комиссии_протокола.csv` | комиссии LayerZero и выручка Stargate по месяцам |
| `transfers/` | полная история переводов ZRO по каждому из проверенных адресов |

### `scripts/` — чем собраны данные

| Скрипт | Что делает |
|---|---|
| `zro_holders_check.py` | выгружает переводы ZRO через Etherscan API, определяет тип каждого адреса, читает владельцев и порог подписей у мультиподписных кошельков, отделяет спам «отравления адреса», собирает крупные переводы за указанный период |
| `zro_market_check.py` | считает изменение цены вокруг каждого разлока с поправкой на биткоин, снимает рыночные показатели, объём и глубину по площадкам, открытый интерес по фьючерсам, комиссии протокола |
| `lz_scan_stats.py` | проверяет, какие сводные данные отдаёт публичный API LayerZero Scan |

Запуск: Python 3.8+, сторонние библиотеки не нужны. Для `zro_holders_check.py` требуется
бесплатный ключ Etherscan — вписать в строку `API_KEY` в начале файла. Остальные два
скрипта ключей не требуют и обращаются к публичным источникам напрямую.

### `appendix/` — проверка источников

## Метод

- Каждое утверждение помечено: установлено, по данным проекта или гипотеза.
- Цифры сверяются с первоисточником; расхождения фиксируются, а не разрешаются выбором
  удобной версии.
- Атрибуция адресов — только при совпадении независимых признаков; где доказательства нет,
  это сказано прямо.

Скрипты написаны с использованием ИИ по собственной постановке задачи; сбор, проверка и
интерпретация данных — самостоятельные.

## Ограничения

- Ончейн-данные собраны только по сети Ethereum; около 49 млн ZRO обращаются в других сетях.
- Принадлежность кошельков конкретным организациям по открытым данным не устанавливается.
- Проверка цены вокруг разлоков построена на 10 наблюдениях — это наблюдение, а не
  статистически доказанная закономерность.
